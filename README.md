# Fame Half-Life

How fast does attention fade after someone becomes news? Daily English Wikipedia pageviews around deaths and major awards, 2016 to 2025.

Design and copy follow [these standards](https://github.com/lyhjeremy/lyhjeremy/blob/main/DESIGN_STANDARDS.md).

Work in progress. The event list in `data/events.csv` was frozen on 2026-10-28, before any pageview was fetched; the queries that produced it are in `queries/`.
