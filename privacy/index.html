Privacy

Last updated 2026-10-28.

This project has no server

Fame Half-Life is a set of static files on GitHub Pages. There is no backend, no database, no account and no form that submits anywhere. Nothing you type on these pages is sent to any server run by this project, because there is none.

Looking up a person in the dataset

The search box under "Look up anyone in the dataset" reads files from this site only (the list of names and the stored pageview series). What you type stays in your browser.

Trying any article

The box under "Try any Wikipedia article" fetches data from Wikimedia, directly from your browser, when you press the button. It makes two requests:

  1. To en.wikipedia.org/w/api.php, with the article title you typed, to check that the article exists and to follow a redirect to its current title.
  2. To wikimedia.org/api/rest_v1/metrics/pageviews, with that title and a date range (from 1 July 2015 to yesterday), to get the article's daily views.

The event date you enter, if any, is not sent: the page picks the days it needs out of the full series in your browser. Both requests are sent without a referrer header. As with any web request, Wikimedia also receives your IP address and your browser's user agent. Its handling of them is covered by the Wikimedia Foundation privacy policy.

The curve fitting runs in your browser. The results are not stored or sent anywhere, and they are gone when you close or reload the page.

Cookies, analytics and other third parties

There are no cookies, no analytics and no third-party scripts. The page stores nothing in your browser's local storage. Fonts are served from this site.

Hosting

GitHub Pages serves the files and keeps standard request logs (IP address, user agent, page requested, time) for its own operations. Those are covered by the GitHub General Privacy Statement.

Deletion requests

This project keeps nothing you enter, so there is nothing to delete. For Wikimedia's or GitHub's logs, use the policies linked above. For questions about this page, email lyhjeremy@gmail.com.
